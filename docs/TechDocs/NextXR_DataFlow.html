2. Machine-twin runtime detail (owner task, 1 Hz per tenant)

Acquire / renew leaseA short Redis lease per tenant. Exactly one task wins and becomes the owner.
Drain command queueThrottle, fault injection and start/stop forwarded by follower tasks are applied here, not locally.
Integrate physicsThe pack's forward model advances one step. Wear accumulates, heat soaks, an injected fault persists.
Compute residualsMeasurement minus the clean-machine baseline — the quantity every Tier-A diagnosis is a statement about.
Evaluate registryWith a _FrameQuery over the latest frame, so cross-signal rules read siblings without a Neo4j round trip.
Persist findings onceThrough the Graph Writer. Only the owner writes, which is what prevents duplicate Finding nodes and duplicate change-log events.
Publish stateThe authoritative frame, once per second.
Followers serve itNever tick, never persist — so every task reports identical values whichever one the ALB picked.

If an owner dies the lease expires after roughly eight seconds and another task adopts the published state, continuing the simulation rather than restarting it. GET /api/v1/health reports this task's twin_runtime.owned list — across the fleet each tenant should appear exactly once.

3. Event bus stream

create update delete finding state connector ingest heartbeat

A BusEvent mirrors the Change Log event — event_id, tenant_id, entity_id, entity_type, label, action, actor, ts — so consumers get the same canonical facts without re-reading the change log. Consumer groups are created per stream when an agent consumer needs one.

5. Solar residual diagnosis — the same pipeline, applied

SignatureConditionDiagnosisAction
Symmetric Output DropΔP < −12% across a zone; Vdc normal; Idc uniformly suppressedSoiling / dust build-upLow-priority cleaning ticket
String Voltage CollapseStep drop in Vdc on a single string; Idc constantBypass diode activation / heavy local shadingHigh-priority structural inspection; isolate the string in red
Shunt Resistance DecayProgressive decline in Rsh over 90 daysPotential-induced degradation (PID) or delaminationSchedule preventative engineering diagnostics next quarter

A PV array's raw output carries almost no information about its condition — 400 kW from a 500 kW array is excellent at 8 a.m. and alarming at noon. The De Soto five-parameter model supplies the missing half: what this array, at this irradiance and this cell temperature, should be producing. Every diagnosis above is a statement about the residual between the two, which is also why the pyranometer and the RTDs are not optional extras — without measured irradiance and cell temperature every “underperformance” alert would just be tracking the sky.
