NextXR Digital Twin — Component Architecture

Layer mapping: client → API → core twin services → platform services → data stores → external systems

Layer 1 — Client
⚛React SPA
  • Vite + React 18, built into the same container image
  • three.js / react-three-fiber 3-D scene with live signal overlays
  • Panels: Dashboard, Twins, Build a Twin, Predict, Copilot, Changelog, Marketplace
  • Domain views: hospital, railway, EV, defence, solar
Served at / · catch-all SPA fallback
🏠GoalCert Hub
  • Mounts the SPA as a Module Federation remote
  • Authenticates with an X-API-Key from NXR_API_KEYS
  • Consumes /api/v1/predict and the AR-overlay surface
VITE_REMOTE_BASE set at build time
📡SSE / Event Stream Client
  • GET /api/v1/bus/stream, scoped to one tenant
  • Drives live dashboard and 3-D scene updates
  • Late joiners backfill from /api/v1/bus/events
ALB idle timeout ≥ 300 s

Layer 2 — API (136 endpoints, 12 routers + a mounted sub-application)
⚡FastAPI Application
  • Uvicorn on :8080, $PORT-driven
  • Routers: graph, write, schema, ingest, historian, connectors, solar, twin-runtime, twins, agents, copilot, hub
  • Neo4j-down handler → one clean 503
server/main.py
🔑AuthMiddleware
  • X-API-Key → role (admin / write / read) + tenant scope
  • SPA at / is exempt
  • NXR_REQUIRE_AUTH closes the dev fail-open path
server/auth.py
🛡enforce_tenant_scope
  • App-level dependency, not middleware — runs after routing
  • Checks the tenant in query, path and body
  • Cannot be forgotten by a route added later
server/tenancy.py
🌐CORS
  • Default * for local dev and the federated hub
  • NXR_CORS_ORIGINS locks it to an allow-list
🗿3-D Platform
  • Mounted at /api/v1/threed
  • Jobs, priors, artifacts, presigned results
  • Mounted apps do not inherit app dependencies

Layer 3 — Core Twin Services
⚙MachineEngine
  • 1 Hz forward-model integration per live twin
  • Wear accumulates; an injected fault persists
  • 11 machine-twin domains discovered from their SPECs
twins/runtime.py
🔐TwinCoordinator
  • One owner per tenant via a short Redis lease
  • Owner ticks and persists findings once
  • Followers serve published state, forward commands
  • ~8 s to adoption if an owner dies
twins/coordinator.py
📊BehaviorRegistry
  • 48 behaviours; Tier A physics, B statistical, C rules
  • watches / reads / emits + evaluate(sample, query)
  • Never touches Neo4j and never writes
behaviors/registry.py
🔗DynamicsEngine
  • Topological ordering over the tenant's edges
  • Cycles broken with a 1-tick lag
  • Real-time with a speed multiplier
dynamics/engine.py
▼validate → commit → changelog → bus▼
Layer 4 — Platform Services
✍GraphWriter
  • The only path that mutates Neo4j
  • SHACL validate, then commit
  • CURIE prefixes registered per pack
🧾ChangeLog
  • Per-tenant hash chain (ULID, prev_event_hash → wm_hash)
  • Advisory lock per tenant so a chain cannot fork
⏱Historian
  • TimescaleDB hypertable + 1m/1h/1d rollups
  • count & sum, never avg
  • Compression 10–20x, retention per tier
🔌ConnectorManager
  • Modbus TCP/RTU, OPC-UA, MQTT + Sparkplug B
  • 7 point-map profiles; SunSpec discovery; OPC-UA browse
  • Ownership lease — one poller per device
🤖Copilot Agents
  • 14 Claude agents, in-process against live state
  • Never raise — deterministic stub fallback
  • Spend accounting + budget cap
📦Storage
  • S3 or local filesystem behind one interface
  • Key-addressed, never path-addressed
  • Health probe writes, reads back and deletes

Layer 5 — Data Stores (each with exactly one job)
◆Neo4j
  • The twin's graph: entities, relationships, findings
  • (tenantId, id) UNIQUE per taxonomy category
  • Schema derived from the ontology TTL
🗃PostgreSQL 16
  • twins, events, published_bundles, checkpoints
  • scene_cache, threed_jobs, ingest_devices, connectors
  • + the TimescaleDB historian on the same instance
⚡Redis 7
  • nxr:events:<tenant_id> streams
  • Twin and connector ownership leases
  • Per-tenant command queues
🗂S3
  • Generated GLBs and 3-D job artifacts
  • Presigned URLs keep large files off API workers

Layer 6 — External Systems
🧠Anthropic Claude
  • Sonnet 5 default; Opus configurable
  • Adaptive thinking on the heavy reasoning agents
  • Keyless → deterministic stubs, ai.backend = "stub"
🖥RunPod GPU
  • TRELLIS serverless container, CUDA 12.1 / 24 GB
  • Deliberately off AWS — bursty GPU work
  • Unset keys → the stage stubs
🏭Field Devices
  • Inverters, PLCs, meters, BMS, weather stations
  • Modbus / OPC-UA / MQTT over TLS
  • Or push directly with an X-Device-Token
📐IFC / Floor Plans
  • 2d-to-3d parser: plan → BIM scene graph
  • IFC parser for existing building models
