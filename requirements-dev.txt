# requirements-dev.txt — the test and lint toolchain.
#
# SEPARATE FROM requirements.txt ON PURPOSE. The container image is built from
# that file and is the deploy artifact; every package in it is code that ships to
# production and widens the attack surface. A test runner, a coverage reporter
# and a linter have no business in a running task.
#
#     pip install -r requirements.txt -r requirements-dev.txt
#
# Pinned for the same reason as the runtime deps: a pytest minor release that
# changes collection behaviour should break a pull request, not a Tuesday.
